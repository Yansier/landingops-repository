# LandingOps V1 产品需求（Phase 1A）

## 1. 产品目标

LandingOps 为一个团队体系提供标准化落地页模板管理、域名授权、单个/批量站点创建、实例配置和部署任务追踪。它降低重复配置 DNS、宝塔站点、文件、SSL 和像素事件的操作成本，同时确保每个已部署站点可以脱离 LandingOps 独立运行。

成功标准：有权限的用户能从获授权模板和主域名创建独立实例；管理员能追踪每一步并安全处理部分失败；LandingOps 不参与访客请求链路；平台不会接管任何既有宝塔站点或现有 DNS 记录。

## 2. 术语

- **控制面**：LandingOps 前端、PHP API、MySQL 和部署任务执行器。
- **站点运行面**：宝塔 Nginx/PHP 托管的实例目录、实例本地配置及可选原生后台。
- **模板 / 模板版本**：业务模板的逻辑身份 / 一次不可变 ZIP 上传。
- **实例**：由某个模板版本、域名和独立配置生成的一个站点。
- **主域名**：已导入 Cloudflare Zone、经团队授权可创建子域名的域名。
- **负责人**：当前可在 LandingOps 内维护实例的员工；创建人永久保留。
- **部署任务**：单实例的可恢复编排；批量部署只是多个同构单站任务的集合。
- **原生后台**：模板可选提供的站点本地后台，使用独立密码，不依赖 LandingOps 身份。

## 3. V1 范围

### 3.1 组织与账号

- 三级角色：总管理员（`super_admin`）、团队管理员（`team_admin`）、员工（`staff`）。
- 用户属于一个团队；总管理员可作为平台级账号不绑定团队。
- 支持停用用户、转交实例、保留创建人和不可覆盖的审计记录。
- V1 采用固定角色加资源范围校验，不建设可自由配置的企业级 RBAC 引擎。

### 3.2 模板库

- 总管理员和团队管理员可上传完整 ZIP。
- 团队管理员上传的模板版本默认授权其团队；总管理员可调整或撤销授权。
- 撤销只阻止后续选用，不下线、不重建、不修改已部署实例。
- 上传时按 LTS v1.0 校验结构、路径、声明与配置 schema；保留原 ZIP、校验结果和 SHA-256。
- 列表只显示名称、版本、描述、上传者、上传团队、能力标签和上传日期，不保存或生成效果图字段。

### 3.3 Cloudflare 与域名

- 总管理员维护多个 Cloudflare 连接；Token 仅后端可解密使用。
- 每个 Zone 归属于一个明确的连接；同一规范化 Zone 名不能被重复导入为两个可用主域名。
- 总管理员向团队授权主域名，员工只能选择自己团队被授权的主域名。
- 子域前缀经规范化和保留词校验后，与主域名组成 FQDN；预留与占用检查必须并发安全。

### 3.4 实例与配置

- 三种角色均可在各自资源范围内单个或批量创建站点。
- 每个实例固定引用一个模板版本，并拥有独立配置、状态、目录、FQDN、创建人、团队和当前负责人。
- 配置范围由模板 schema 限定，重点包括多个 Pixel ID、真实行为事件、下载/跳转链接和自定义字段。
- `Download`、`AddToCart`、`Purchase` 事件只能挂接相符的真实操作；金额默认 `1 USD` 且可修改。
- 原生后台默认关闭；仅模板声明支持时可在创建时启用。关闭必须由 Web 服务器规则或不发布后台入口实现真实阻断。
- LandingOps 修改配置和原生后台修改配置都遵循同一版本契约，采用乐观锁、原子替换与审计。

### 3.5 部署任务

- 编排 DNS、宝塔站点、文件发布、可选后台限制、SSL、HTTPS 和最终验证。
- 每一步持久化状态、尝试次数、脱敏错误、外部资源标识和幂等键。
- 默认不覆盖 DNS；既有宝塔站点只检测冲突。
- 失败可重试；部分完成必须清楚展示；补偿仅删除本任务已创建且仍满足所有权证据的资源。
- 批量任务由多个单站任务组成，可出现部分成功，不另建第二套部署逻辑。

### 3.6 备用页与外部组件

- 总管理员可维护普通备用 HTML 资产版本。当前参考文件为 `references/LandingOps_Backup_Bubble_Page.html`。
- 供应商 `index.php` / `core.php` 是独立外部组件，不并入基础模板 ZIP；记录版本、文件哈希、PHP 要求和配置边界。
- 不设计对审核/检测人员展示不同内容、随机隐藏文件或规避审核的分流能力。

## 4. 角色权限矩阵

`全部` 表示平台全部资源；`本团队` 表示必须由后端校验 `team_id`；`本人负责` 表示当前负责人为该用户。创建人不是永久编辑权限的替代品。

| 能力 | 总管理员 | 团队管理员 | 员工 |
| --- | --- | --- | --- |
| 团队/用户管理 | 全部 | 查看本团队；管理本团队员工 | 查看本人资料 |
| 宝塔连接设置 | 管理唯一配置 | 无 | 无 |
| Cloudflare 连接/Zone 导入 | 全部 | 只读已授权主域名 | 只读已授权主域名 |
| 主域名团队授权 | 全部 | 查看本团队授权 | 查看本团队授权 |
| 上传模板版本 | 可 | 可，归属本团队 | 不可 |
| 查看模板 | 全部 | 自建及获授权 | 获授权 |
| 调整/撤销模板授权 | 全部 | 无 | 无 |
| 创建单个/批量实例 | 任意团队 | 本团队 | 本团队，默认负责人为本人 |
| 查看实例 | 全部 | 本团队 | 本人负责 |
| 修改实例配置 | 全部 | 本团队 | 本人负责 |
| 转交负责人 | 任意合法团队用户 | 本团队成员间 | 不可 |
| 重试/取消部署任务 | 全部 | 本团队 | 本人负责实例；仅允许安全状态 |
| 查看审计日志 | 全部 | 本团队资源 | 本人相关操作摘要 |
| 管理备用 HTML/供应商组件元数据 | 全部 | 无 | 无 |

所有写操作及敏感读操作必须在 PHP API 中执行认证、角色、团队、资源所有权和状态校验。前端菜单隐藏只改善体验，不构成授权。

## 5. 核心用户流程

### 5.1 单站创建

1. 用户选择有权使用的模板版本和主域名。
2. 输入子域前缀；系统本地检查格式、保留任务、实例记录，并在执行阶段核验宝塔站点和 Cloudflare 记录。
3. 填写 schema 允许的配置，选择真实事件及金额；若模板支持，可显式启用原生后台并设置独立密码。
4. 后端再次鉴权和校验，创建实例草稿、域名预留及单站部署任务；事务提交后返回任务 ID。
5. 任务执行器逐步调用适配器并记录结果。用户查看状态，必要时在安全条件下重试或请求管理员处理冲突。
6. 最终验证通过后实例进入 `active`；站点从自身目录与本地配置运行。

### 5.2 批量创建

1. 用户提交若干行，逐行指定子域、模板、配置和负责人；同批可共享受权主域名与公共默认值。
2. 后端逐行完成权限、格式和批内重复校验，展示可提交行与错误行；用户确认后创建批次。
3. 每个有效行生成独立实例、预留和单站任务，沿用同一状态机与幂等规则。
4. 批次聚合 `queued/running/succeeded/failed/partial/cancelled` 数量；单行失败不回滚其他成功站点。
5. 只重试失败任务，不重复执行成功任务。

### 5.3 实例转交

1. 总管理员或团队管理员选择当前实例和同团队的启用用户。
2. 后端锁定实例，校验操作者范围、目标用户状态和团队一致性。
3. 更新 `current_owner_user_id`，写入负责人历史和审计日志；`created_by_user_id` 永不修改。
4. 旧负责人失去 LandingOps 编辑权；站点内容和运行不受影响。原生后台密码不会因转交自动共享或轮换，需另行显式操作。

### 5.4 配置修改

1. 客户端读取当前 `config_version` 和按 schema 脱敏后的配置。
2. 用户提交期望版本、补丁/完整配置和变更原因。
3. 后端校验权限、schema 与业务语义，读取站点当前本地版本；不一致返回冲突，不强行覆盖。
4. 通过临时文件、校验、原子重命名发布新版本，并在数据库记录结果；失败时保留旧文件。

## 6. 状态与业务规则

- 实例建议状态：`draft`、`reserved`、`deploying`、`active`、`degraded`、`failed`、`disabled`、`archived`。
- 域名预留必须有唯一 FQDN 和过期时间；活动任务续租。只有确认无外部资源或已安全补偿后才释放。
- 模板版本发布后不可原位改 ZIP；修复产生新版本。实例不会被自动升级。
- 停用模板授权、用户或 Cloudflare 连接不得隐式删除站点。
- 删除/下线属于高风险的独立后续流程；V1 需求未授权自动清理已部署站点。

## 7. 明确排除

- 多宝塔、服务器池、负载均衡、自动选服务器。
- LandingOps 代理或参与访客流量；站点运行时查询 LandingOps。
- 接管、覆盖、删除或批量改写既有宝塔站点及非 LandingOps DNS。
- 模板截图、缩略图、效果图、自动截图、独立预览服务。
- 本阶段的 Vue 界面、PHP 业务 API、数据库迁移、任务执行器和真实 API 联调。
- 自建 Nginx/PHP 运行平台、对象存储或大媒体系统。
- 审核规避、访客身份分流、随机隐藏文件名等功能。
- 自由编排式企业 RBAC、跨团队协作实例、自动模板升级。

## 8. 非功能要求

- **安全**：凭据加密、最小权限、日志脱敏、后端授权、ZIP 安全解压、审计不可静默覆盖。
- **可靠**：任务可恢复、步骤幂等、所有权校验后补偿、配置原子写入。
- **隔离**：每实例独立目录和配置；控制面故障不影响运行面。
- **可观测**：任务/步骤状态、关联 ID、耗时、重试次数和人工处置提示；不得记录密钥。
- **可维护**：适配器隔离宝塔/Cloudflare 版本差异；模板按 LTS 契约验证。
